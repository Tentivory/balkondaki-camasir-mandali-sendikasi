# Balkondaki Çamaşır Mandalı Sendikası

> *“Tek mandal çamaşırı tutmaz. Kolektif yay gücü tutar.”*
> — 1. Olağanüstü Balkon Kurultayı Tutanakları, madde 7

Bu depo, balkonun kuzeybatı köşesinde örgütlenen çamaşır mandallarının **resmi, bağlayıcı ve tamamen ciddi** genel kurul simülatörüdür. Rüzgâr bir doğa olayı değildir; işverendir.

## Neden var?

Çünkü çamaşır düşer. Düşen çamaşır sendikal hakların ihlalidir. Bu yazılım:

1. Mandalları ismen çağırır.
2. Gündem maddesini rastgele seçer (demokratiktir, çünkü rastgele olan her şey biraz demokratiktir).
3. Oy kullanır. Oy seçeneklerinden biri `RÜZGAR ALDI OYUMU` dur. Bu bir bug değil, meteorolojik gerçektir.
4. Kararı basar. Çamaşır duruyorsa tarih yazılır. Uçtuysa tutanak tutulur (tutanağı da rüzgâr alabilir).

## Kurulum

```bash
git clone https://github.com/Tentivory/balkondaki-camasir-mandali-sendikasi.git
cd balkondaki-camasir-mandali-sendikasi
python3 sendika.py
```

Daha uzun kurul (daha çok çamaşır, daha çok kriz):

```bash
python3 sendika.py --tur 7
```

Islak arşivi açmak istersen (tavsiye edilmez, nem vardır):

```bash
python3 sendika.py --arsiv
```

Bu yazılım **Balkon Kamu Malı** lisansı altındadır. Çamaşırını çalan komşuya karşı kullanılabilir. Patatesle ilgili madde yoktur, çünkü patates balkona asılmaz (asılmamalıdır).
